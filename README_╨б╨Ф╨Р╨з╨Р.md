# Что делать с этим архивом

1. **Распакуйте архив** у себя на компьютере.
2. **Создайте пустой репозиторий** на GitHub (публичный, без README).
3. **Загрузите файлы** в репозиторий (можно через веб-интерфейс GitHub: "uploading an existing file").
4. **Создайте зеркало на DagsHub**: DagsHub -> Create -> Connect a repository -> выберите свой GitHub репозиторий.
5. **Откройте Colab** и загрузите ноутбук `notebooks/lr1_data_and_pipeline.ipynb`.
6. **Заведите секреты в Colab** (значок ключа слева): `GITHUB_USER`, `GITHUB_TOKEN`, `DAGSHUB_USER`, `DAGSHUB_TOKEN`.
7. **Запускайте ячейки по порядку**. Скрипт сам скачает данные, настроит DVC, запустит пайплайн и сделает коммиты.

## Важно

- В `params.yaml` уже прописаны все параметры (модель, гиперпараметры, порог R2).
- В `dvc.yaml` описан пайплайн из 4 этапов.
- В `src/` лежат все Python-модули.
- В `tests/` есть тесты (pytest).
